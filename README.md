# Astra Roadster — 3D分解ビューア

赤いオープン2シーター「Astra Roadster」を、Three.js のコードだけで組み立てた3Dモデルで展示するビューアです。三面図（上・横・正面）の画像から輪郭を読み取り、ボディを生成しています。

## できること

- ドラッグで回転、ホイールやピンチで拡大縮小
- 「上」「横」「正面」「視点リセット」で視点を切り替え
- 「パーツ分解」で61点の部品を、外装・内装と足まわり・シャーシの3層に分解
- 「始動」でシザードアが跳ね上がり、ホイールが回転し、ライトが点灯
- 部品にカーソルを重ねる（スマホではタップする）と部品名を表示
- 展示室とスタジオの2つのテーマを切り替え

## 見るには

`index.html` をブラウザで開いてください。Three.js を CDN から読み込むため、インターネット接続が必要です。

## 開発

```bash
npm install
npm test          # テスト
npm run build     # index.html を生成
npm run serve     # http://localhost:5178/ で確認
```

`npm run extract` は `../Astra_Roadster/` にある三面図画像から `src/blueprint.js` を作り直します。画像はこのリポジトリには含まれていません。
